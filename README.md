# Brew & Bite Café Website

## Future Interns – Prompt Engineering Internship

### Task 1: AI Website Copy Generator for Local Businesses

## Project Overview

This project was developed as part of the Future Interns Prompt Engineering Internship. The objective was to use AI-powered prompt engineering to generate a professional, responsive website for a local café.

The website was created using Lovable AI and includes modern design, engaging website copy, and customer-focused features suitable for a real business.

## Prompt Engineering Process

A structured prompt was created to instruct the AI to design a complete website for a local café. The prompt specified:

- Business type
- Target audience
- Website sections
- Design requirements
- Color theme
- Features
- Responsive layout
- SEO-friendly content

The AI generated a complete website based on these instructions, which was then reviewed and refined.
